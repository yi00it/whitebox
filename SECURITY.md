# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub: go to the [Security tab](https://github.com/yi00it/whitebox/security) and click **Report a vulnerability**. You'll get a reply as soon as possible, and a fix will be released before details are made public.

## Supported versions

Only the [latest release](https://github.com/yi00it/whitebox/releases/latest) receives security fixes.
